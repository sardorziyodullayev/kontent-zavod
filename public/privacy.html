PixelMind Studio (Kontent Zavod) · oxirgi yangilanish: 2026-yil 20-oktabr

PixelMind Studio — PixelMind jamoasining o‘z videolarini ijtimoiy tarmoqlarga rejalashtirish, joylash va natijalarini kuzatish uchun ishlatadigan ichki vosita. U faqat egasi tomonidan, egasining o‘z akkauntlari bilan ishlatiladi.

Qanday ma’lumotlarga kiriladi

  • YouTube (Google): youtube.upload ruxsati — tayyorlangan videolarni kanalga yuklash; youtube.readonly — kanal obunachilari soni va yuklangan videolarning ko‘rish, layk, izoh sonlarini o‘qish.
  • Telegram: bot orqali kanalga post joylash va obunachilar sonini o‘qish.

Ma’lumotlar qayerda saqlanadi

Kirish tokenlari, video fayllar va statistika faqat vosita egasining serverida saqlanadi. Ular uchinchi shaxslarga berilmaydi, sotilmaydi, reklama yoki boshqa maqsadda ishlatilmaydi.

Google foydalanuvchi ma’lumotlari

Google API’laridan olingan ma’lumotlardan foydalanish Google API Services User Data Policy talablariga, jumladan Limited Use talablariga mos keladi. Ma’lumotlar faqat yuqorida yozilgan vazifalar uchun ishlatiladi.

Ruxsatni bekor qilish va o‘chirish

Ruxsatni istalgan vaqtda Google akkaunt sozlamalarida bekor qilish mumkin. Shundan keyin vosita YouTube’ga kira olmaydi. Server ma’lumotlari egasining so‘rovi bilan to‘liq o‘chiriladi.

Privacy Policy (English)

PixelMind Studio (Kontent Zavod) is an internal tool used solely by its owner to schedule, publish and track videos on the owner’s own social media accounts.

  • YouTube: the youtube.upload scope is used to upload the owner’s videos; youtube.readonly is used to read channel subscriber count and video view, like and comment counts.
  • Storage: access tokens, video files and statistics are stored only on the owner’s server. They are never shared, sold, or used for advertising.
  • Google user data: use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revoking access: access can be revoked at any time at myaccount.google.com/permissions; stored data is deleted on request.
  • Contact: GitHub issues.
